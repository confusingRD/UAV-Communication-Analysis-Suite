## 2026-11-17 — Phase 2A bounded spherical ray BVP (**Reconstructed**)

- **Phase:** Phase 2A
- **Objective:** Implement and numerically verify the initial bounded, nonducting spherical endpoint BVP for UAV-to-ground propagation while preserving the CubeSat baseline.

- **Historically reported commands:** `.venv-science\Scripts\python.exe -m pytest -q`; `.venv-science\Scripts\python.exe -m uav_cas.phase2a_demo --output-dir outputs\phase2a`.
